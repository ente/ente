# Create Account and Log In

Ente Locker uses the same account system as Ente Photos and Ente Auth. If you already have an Ente account, you can use your existing credentials.

## Creating a new account

1. Open Ente Locker
2. Tap **Create an Ente account**
3. Enter your email address
4. Create a strong password
5. Verify your email with the code sent to you
6. **Important**: Save your recovery key when prompted

![Create account form on Ente Locker mobile with email frosted](https://docs-assets.ente.com/screenshots/locker-signup-create-account.png){width=320px}

> [!WARNING]
>
> Your recovery key is the primary way to access your account if you forget your password. Store it securely in multiple locations, and set up Legacy recovery if someone else may need to recover the account.

## Logging in

1. Open Ente Locker
2. Tap **Login to existing account**
3. Enter your email and password
4. If you have two-factor authentication enabled, enter your 2FA code

![Login to existing account highlighted on the Ente Locker mobile welcome screen](https://docs-assets.ente.com/screenshots/locker-sign-in-v1013.png){width=560px}

## Using an existing Ente account

If you already use Ente Photos or Ente Auth:

1. Open Ente Locker
2. Tap **Login to existing account**
3. Enter your existing Ente email and password
4. Your Locker data is securely stored

![Login to existing account highlighted on the welcome screen, then the email step on Ente Locker mobile](https://docs-assets.ente.com/screenshots/locker-sign-in-existing-v1013.png){width=560px}

## Recovery key

Your recovery key is a 24-word phrase generated when you create your account. This is critical for account recovery.

![Recovery key save screen on Ente Locker mobile with key frosted](https://docs-assets.ente.com/screenshots/locker-signup-recovery-key.png){width=320px}

**Best practices for storing your recovery key:**

- Save it in a password manager
- Write it down and store in a secure location
- Keep copies in multiple places
- Never share it with anyone

Learn more about [security in Ente Locker](/locker/features/security/).

## Account limits

Locker has storage limits based on your subscription:

- **Free plan**: Up to 100 items and 1GB total storage
- **Paid plan** (any Ente subscription): Up to 1000 items and 10GB total storage

### What counts as an item

Each of these counts as one item toward your limit:

- Each uploaded document (PDF, image, scan)
- Each personal note
- Each set of account credentials
- Each physical record entry

### Checking your usage

Open the Locker menu and check the **Items stored** card to see how many items you have and how much storage you're using.

![Locker menu button highlighted, then the Items stored card in the Locker menu on Ente Locker mobile](https://docs-assets.ente.com/screenshots/locker-settings-storage-v1013.png){width=560px}

### Upgrading your plan

If you reach your item or storage limit, upgrade to any Ente paid plan to increase your limits to 1000 items and 10GB storage.

Learn more about [account limits FAQ](/locker/faq/getting-started#locker-account-limits).
