# Ente QR

[Ente QR](https://qr.ente.com) is a free web app for turning a link or text into a QR code. Use it for a poster, menu, business card, invitation, or anything else you want someone to scan.

No account is required, and there are no ads or tracking.

## How it works

1. Open [qr.ente.com](https://qr.ente.com).
2. Type or paste your link or text. The QR code appears as you type.
3. Customize its appearance, or keep the default style.
4. Download the QR code as an SVG, or use the sharing options.
5. Scan the finished code with your phone to check it before sharing or printing.

## Customize your code

You can change the code's shape, corners, and eyes (the markers in its corners), and choose separate colors for the code, eyes, and background. Add a frame or upload a logo to put in the center.

Keep strong contrast between the code and its background. After changing colors or adding a logo, test that the code still scans at the size and distance you intend to use it.

## Share your QR

The share panel lets you add an optional message and share the QR as a card or save it as an image. For a scalable version to use in a design or print layout, download the SVG.

## Privacy and lasting links

QR generation happens in your browser. Your link or text goes directly into the code, without an Ente redirect or scan tracking.

The code does not expire. A code containing a link will keep pointing to that address, so the destination still needs to remain available. To encode a different address, create a new code.

Anyone who scans the code can read its contents. A QR code does not encrypt your text or restrict access to it.
