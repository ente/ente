### FairScan

Ente Locker's document scanner uses the [FairScan segmentation model](https://github.com/pynicolas/fairscan-segmentation-model) by Pierre-Yves Nicolas, converted to ONNX for Ente's ML runtime. The model is licensed under [GNU GPLv3](https://github.com/pynicolas/fairscan-segmentation-model/blob/main/LICENSE).

Parts of the original scanner were adapted from [FairScan's image-processing code](https://github.com/pynicolas/FairScan), also licensed under [GNU GPLv3](https://github.com/pynicolas/FairScan/blob/main/LICENSE).
